HızlıKitapOku Nedir?

Kitapları RSVP, Bionic, Harf Harf gibi hızlı okuma teknikleriyle, her gün küçük oturumlarla okumanı sağlayan ücretsiz ve açık kaynak uygulama. Hesap yok, reklam yok; kitapların sadece senin cihazında kalır.

Google Drive Bağlantısı
1. Google Cloud Console'a git → Proje oluştur → Drive API'yi etkinleştir → API Key oluştur
2. Google Drive'da klasörünü aç → Paylaş → "Bağlantısı olan herkes" → Görüntüleyici
3. Klasörün URL'sini buraya yapıştır (klasör ID otomatik çekilir). PDF'ler de akıllı temizlemeden geçer.
